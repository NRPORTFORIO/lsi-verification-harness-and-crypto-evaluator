# LSI Verification Harness & Crypto Evaluator
C言語による「LSIレジスタ制御エミュレータ」と、Pythonによる「LSI出力データの暗号化・自動検証ハーネス」のハイブリッド型検証システムです。

東証スタンダード上場・株式会社アクセル様の「自社開発LSIを対象としたソフト開発・検証業務」への絶対的な適性を客観的に証明するために構築いたしました。

##  開発背景と設計思想
株式会社アクセル様が注力されている「遊技機器向けグラフィックスLSI」のトータルサポート業務、および「AI、セキュリティ、ブロックチェーン」といった新規事業領域から逆算し、実務で求められる技術要素を個人開発レベルで具現化しました。

専門業務型裁量労働制（みなし1日9時間労働）という、高度な自走力とプロ意識が求められる環境を意識し、手元にPC環境がないという過酷な制約下であっても「スマートフォン環境（Pythonista3/Wandbox）」と生成AIをシニアエンジニアとして仮想共創させ、仕様設計からデバッグまでを完全自力で完結させています。

##  システムアーキテクチャ & 実装内容

### 1. C言語レイヤー (`main.c`): LSIグラフィックスレジスタ・エミュレーション
半導体（LSI）のハードウェア制御において最も重要となるレジスタ（VRAM、グラフィックス描画バッファ等）の挙動を低レイヤーで再現。
* **ビットフィールド・ビット演算の徹底適用:** 
  漫然と `int` 型（4バイト）を使用せず、`uint8_t` などの固定幅整数型とビットフィールド（1ビット〜3ビット単位の構造体定義）を徹底適用。データ領域を1変数あたり75%削減し、「製品量産時におけるワンランク安価なマイコンチップの選定（原価低減・デザインイン視点）」を設計レベルで実現。
* **Enumによるパケットエラーの一元管理:** 
  LSI内部でのデータ転送エラーやパリティチェック（データ破損検知）をシミュレートし、システムをアベンド（異常終了）させず、エラーコードを上位アプリケーションへ高速に引き渡す例外ハンドリングを実装。
* **ポインタ直接参照:** 無駄なメモリコピーを徹底的に排除した、超高速・省メモリなデータ更新を実現。

### 2. Pythonレイヤー (`analyzer.py`): 次世代領域を見据えた自動検証ハーネス
アクセル様が注力する「ブロックチェーン・情報セキュリティ」の要素技術をシミュレート。
* **暗号化（Crypto）要素技術のシミュレート:** 
  LSIから出力された描画ログデータに対して、Pythonを用いたSHA-256ハッシュ化によるデータ改ざん防止の検証プロセスを自動構築。
* **テスト自動化（AIOps）による検証工数の極小化:** 
  数万件に及ぶLSIのレジスタ書き換えログを正規表現（`re`モジュール）で超高速パースし、設定値のズレやデータ改ざんを自動検知して `[PASS]` / `[FAIL]` を出力。実実務における「大幅な検証工数・人件費（タイムコスト）の削減（仕事スタイルD）」を再現。

##  活かせる資質・ビジネス感覚
* **裁量労働制に対応する「自走力」:** 
  誰かに指示される前に、求人要件から逆算してLSI検証のモックアップを自発的に企画・設計・構築する圧倒的な「積極性と実行力（診断データ60）」。
* **工業簿記のコスト感覚と技術の融合:** 
  「検証フェーズの自動化による人件費削減」と、「LSIのバグ（脆弱性）を早期に自動検知することによる量産後のリコールコスト（財務損失）の防止」を経営視点で客観的に両立。

##  動作確認方法
### C言語環境
Wandbox等のGCCコンパイラ環境にて `main.c` を実行。レジスタ展開ログ、パリティ演算結果、およびアドレス超過時の例外検知ログ（`ERR_INVALID_VRAM_ADDR`）が出力されます。

### Python環境
Python 3.x 環境にて `analyzer.py` を実行。C言語が出力したログを自動パースし、エラー検知時の `[FAIL]` 判定、および正常ログに対する SHA-256 暗号署名の自動付与レポートが出力されます。
