# lsi-verification-harness-and-crypto-evaluator
株式会社アクセルのLSI開発・検証業務への適性を客観的に証明するため構築した、C言語による「LSIレジスタ制御」とPythonによる「自動検証（セキュリティ/AI領域対応）ハーネス」のハイブリッド型検証システム。手元にPCがない制約を言い訳にせず、スマホ環境と生成AIを共創させ自力で具現化。【C言語】半導体制御に必須となるレジスタ挙動を再現するため、ビットフィールドやビット演算を徹底適用。エラーの一元管理で例外処理を実装。【Python】注力事業である暗号化要素（SHA-256等）の検証プロセスをシミュレート。数万件のレジスタログを正規表現で高速パースし、設定値のズレを自動検知する仕組みを構築。検証工数の極小化という実務（経営コスト削減）視点を具現化。
